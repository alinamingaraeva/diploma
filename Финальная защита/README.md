# Финальная защита — что лежит в этой папке

Сюда собраны материалы итоговой аттестации. Код проекта по-прежнему в корне репозитория.

| Файл | Зачем |
|------|--------|
| `Презентация-ИА-финальная-2026-09-23.pptx` | Актуальная финальная версия на 12 слайдов. Архитектура показывает два источника: официальный сайт для свежих сведений и локальный RAG для устойчивых фактов и резерва. |
| `сценарий-видео.md` | Исходный короткий сценарий видео на 5–7 минут; оставлен без изменений |
| `сценарий-видео-максимально-подробный.md` | Пошаговый сценарий для записи: что нажать, что показать, что сказать и зачем это делается |
| `текст-на-защите.md` | Речь 8 минут + короткие ответы |
| `блок-усиления.md` | Можно ли закрыть необязательный блок и план |
| `аудит-и-git.md` | Все ли ДЗ сданы, что потом класть в git |
| `build_pptx.py` | Архивный генератор ранней версии презентации; для защиты используйте готовый PPTX от 23.09.2026 |

В корне проекта для ИА также нужны (уже сделаны): `README.md`, `docker-compose.yml`, `.env.example`, `docs/decisions.md`, `docs/limitations.md`.
