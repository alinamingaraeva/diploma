# Результаты бенчмарка (ДЗ 3.3)

Фактический прогон: **18.09.2026**, Windows 11, Python 3.12, модель `gpt-4o-mini` через OpenAI-совместимый API Polza. Для всех режимов использованы одинаковые 20 промптов; ошибок запросов не было.

Команда:

```bash
python -m scripts.benchmark --n 20
```

| Режим | Общее время | Ускорение к sync |
| --- | ---: | ---: |
| sync, последовательно | 68,07 с | 1,00× |
| async, concurrency=1 | 59,11 с | 1,15× |
| async, concurrency=5 | 14,98 с | 4,54× |
| async, concurrency=10 | 8,36 с | 8,14× |

Потоковый запрос: **TTFT 0,98 с**, полное время **2,19 с**, получено 66 дельт. Первый токен пришёл на 1,21 с раньше полного ответа, поэтому требование `TTFT < total` выполнено.

Вывод: при `concurrency=10` реальный прогон дал ускорение **8,14×**, что выше целевого диапазона задания 4–5×. `concurrency=1` немного быстрее sync из-за сетевой вариативности, но основное ускорение даёт перекрытие ожидания HTTP-ответов. Rate limit и ошибки провайдера в этом прогоне не наблюдались.
