# Ограничения системы

Честный список для защиты: где система не работает или работает хуже, чем кажется.

## Отказывается или должна отказываться

- Факты вне корпуса (спорт, политика, другие города) — score-guard 0.38 или промпт отказа. Не «я знаю из интернета».
- Слишком общий вопрос («что такое музей») — может ответить расплывчато; такие пары выкинуты из golden, чтобы не ломать citation.
- Follow-up без истории («а это?») — зависит от `_condense`; если историю очистили `/clear`, поиск слепой.

## Где ошибается

- Судья RAGAS иногда ставит faithfulness 0.0 на дословный ответ из чанка (пример: билет 450 ₽). Это шум метрики, не обязательно баг ретривера — смотреть `context_recall`.
- Кнопки меню и `museum_kb.json` могут разъехаться с RAG, если правили только `data/museum/*.md`.
- Writer в экспериментальном мультиагенте снимал цитаты и на двух фактах сразу отказывал — поэтому мультиагент в прод не берём.
- ReAct-критик на задаче «найди и отправь» мог дважды нажать заглушку отправки (ложный REVISE).

## Чего нет в боевом контуре посетителя

- Бот **не** вызывает агентный граф 6.4. Посетитель идёт в RAG-чат. Агент — отдельный `POST /agent/stream`.
- `send_telegram_message` агента — **print**, не Bot API. Подтверждение человека учебное.
- Re-ranker выключен. Коллекция `documents` из ДЗ 5.2 ботом не используется.
- Отдельного лимита «N запросов в минуту на посетителя» в коде нет: есть обработка 429 провайдера и Semaphore на клиенте. В схеме архитектуры слово rate-limit относится к этому контуру и к плану усиления, не к slowapi.
- Публичный 24/7 прототип не гарантируется: домашний ПК выключают. Для ИА надёжнее видео.

## Инфраструктура

- Windows + async Postgres checkpointer агента: локально sqlite, postgres — в Linux-контейнере.
- Первый символ `.env` с BOM на Windows ломал ключ — чтение `utf-8-sig`.
- pydantic 2.11.7 зафиксирован из‑за aiogram 3.22.

## За рамками диплома

- Оператор живой очереди и эскалация в реальный отдел музея (фраза «могу эскалировать» без тикета).
- Мультиагентный research.
- Своя GPU и локальная 70B.
- Прод-секреты, TLS, настоящий лимит Telegram Bot API кроме debounce 700 мс.
