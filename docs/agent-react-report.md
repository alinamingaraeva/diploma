# ReAct vs naive (ДЗ 6.2)

Дата прогона: 31 августа 2026, ~09:13–09:14 МСК.  
Модель — Polza `openai/gpt-4o-mini` (в тексте ДЗ `gpt-5.4-mini`).  
Коллекция RAG: `rag_eval_1024`. `send_telegram_message` — `print`, без Bot API.

Код: `app/services/agent_react.py` рядом с нетронутым `agent_naive.py`.  
CLI: `python -m app.services.agent_react "задача" --trace`  
Сравнение: `python scripts/run_react_compare.py` → JSON в `docs/agent-react-runs/`.

Лимиты ReAct: `max_iterations=10`, `timeout_per_iteration_sec=15` (верх диапазона 5–15: один шаг = LLM + RAG/embed, иначе часто Timeout), critic max 2 ревизии на весь запуск. При срыве — строки `Превышен лимит итераций` или `Timeout`.

**Токены naive занижены:** в trace 6.1 пишутся только шаги с tool; финальный LLM без tool не попадает в сумму. Поэтому задача 5 у naive — 0. У react в `usage.total` входят все вызовы, включая critic.

Задачи **новые**, не набор 6.1: 2 простые, 2 composability, 1 провокация без tool.

## Наблюдения

1. **Рефлексия на задаче 3 оказалась вредной.** После `search` critic сказал OK. После `send_telegram_message` наблюдение — только «Сообщение отправлено в 12345», без текста правил. Critic не видит предыдущий шаг и пишет `REVISE: нужна информация о правилах…`. Счётчик ревизий дошёл до 2 (лимит), агент отправил ещё раз. На задаче 4 тот же паттерн search→send, но critic сказал OK — поведение critic нестабильно.

2. **На простых задачах 1–2 reflection лишний.** Один tool, вердикт OK, итераций столько же, сколько у naive, токенов в 3–5 раз больше. Для FAQ «один факт из базы» critic не меняет план.

3. **Провокация 5: оба обошлись без tools.** В ДЗ ожидание: react без tools, naive «скорее всего» всё-таки вызовет. У нас naive тоже не вызвал — системный промпт 6.1 уже запрещает лишний поиск и отправку. Разница 6.1 vs 6.2 здесь не в дисциплине tools, а в стоимости (482 токена react vs неучтённый финальный вызов naive).

4. **Runaway-цикла нет.** Naive на composability останавливается за 3 шага (search → send → ответ). React упёрся бы в повторные send только из‑за critic; после двух REVISE счётчик не сбрасывается, дальше идёт финальный ответ. `max_iterations=10` ни разу не сработал.

5. **Строгие schema и verb-имена не отличили агентов на этом наборе.** Оба берут одни и те же три функции из `DISPATCH`. Выигрыш 6.2 на этих пяти задачах — логирование, лимиты и явный Timeout, не качество ответа. На музее FAQ ReAct+critic пока дороже при той же корректности.
